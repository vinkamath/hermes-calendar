Privacy Policy

Last updated: 4 November 2026

Hermes Calendar accesses Google Calendar data (scope: https://www.googleapis.com/auth/calendar) solely for the account owner who authorized it, to read, create and update that owner's calendar events on their instruction.

Data is not sold, shared with third parties, or used for advertising. OAuth tokens are stored on the owner's private server with restricted file permissions. Event data is processed only to fulfil the owner's requests and is not retained beyond that.

Hermes Calendar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

You can revoke access at any time at myaccount.google.com/permissions. Questions: GitHub issues
